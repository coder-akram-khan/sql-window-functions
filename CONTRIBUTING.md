# Contributing Guidelines 

Thank you for your interest in contributing to this repository!

This project is meant to be **beginner-friendly**, **interview-focused**, and **community-driven**.

---

## 🛠 How to Contribute

### Step 1: Fork the Repository
Click the **Fork** button on GitHub.

### Step 2: Clone Your Fork
```bash
git clone https://github.com/<your-username>/sql-window-functions.git
````

### Step 3: Create a New Branch

```bash
git checkout -b feature/your-feature-name
```

---

## ✨ What You Can Contribute

* New window function questions
* Optimized or alternative SQL solutions
* Advanced analytical use cases
* Database-specific variations (PostgreSQL / MySQL / SQL Server)
* Documentation improvements

---

## 📌 Contribution Rules

Please ensure:

* SQL is **readable and well-formatted**
* Queries are **well-commented**
* Window functions are used where appropriate
* Avoid unnecessary complexity
* Follow standard SQL conventions

---

## 📂 Where to Add Your Changes

| Contribution Type    | Folder                         |
| -------------------- | ------------------------------ |
| New Questions        | `practice-questions/`          |
| Solutions            | `solutions/`                   |
| Dataset Improvements | `datasets/`                    |
| Documentation        | `README.md`, `CONTRIBUTING.md` |

---

## 🚀 Submitting a Pull Request

1. Commit your changes:

   ```bash
   git commit -m "Add <short description of change>"
   ```

2. Push your branch:

   ```bash
   git push origin feature/your-feature-name
   ```

3. Open a Pull Request on GitHub.

---

## 🙌 Code of Conduct

Be respectful, constructive, and supportive.
This repository exists to **learn together and grow together**.

Happy contributing :)
